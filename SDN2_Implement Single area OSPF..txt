==================================================
PRACTICAL 2
AIM: Implement Single area OSPF
==================================================

Step 1: Add 4 routers (1841): Router0, Router1, Router2, Router3 and 1 switch (2950T-24): Switch0.

Step 2: Add HWIC-2T module to Router2 and Router3 (click router > Physical tab > power off > add module > power on).

Step 3: Connect using Automatic connection:
   * Router0 fa0/0 --- Switch0
   * Router1 fa0/0 --- Switch0
   * Router2 fa0/0 --- Switch0
   * Router2 se0/1/0 --- Router3 se0/1/0  (network 172.16.0.0)

Step 4: Assign IP addresses (loopback 0, fa0/0, serial):
REFERENCE LIST ONLY, no action needed here.
        Move to Step 5 (the IPs are assigned there using the commands):

   * R0: Lo 10.10.20.1/24 | fa0/0 192.168.0.2/24
   * R1: Lo 10.10.10.1/24 | fa0/0 192.168.0.1/24
   * R2: Lo 10.10.30.1/24 | fa0/0 192.168.0.3/24 | Se0/1/0 172.16.0.1/30
   * R3: Lo 10.10.40.1/24 | Se0/1/0 172.16.0.2/30

Step 5: Configure the interfaces:

 Configure R0
   Router>en
   Router#conf t
   Router(config)#int loopback 0
   Router(config-if)#ip add 10.10.20.1 255.255.255.0
   Router(config-if)#no shut
   Router(config-if)#exit
   Router(config)#int fa0/0
   Router(config-if)#ip add 192.168.0.2 255.255.255.0
   Router(config-if)#no shut
   Router(config-if)#exit

 Configure R1
   Router>en
   Router#conf t
   Router(config)#int loopback 0
   Router(config-if)#ip add 10.10.10.1 255.255.255.0
   Router(config-if)#no shut
   Router(config-if)#exit
   Router(config)#int fa0/0
   Router(config-if)#ip add 192.168.0.1 255.255.255.0
   Router(config-if)#no shut
   Router(config-if)#exit

 Configure R2
   Router>en
   Router#conf t
   Router(config)#int loopback 0
   Router(config-if)#ip add 10.10.30.1 255.255.255.0
   Router(config-if)#no shut
   Router(config-if)#exit
   Router(config)#int Serial0/1/0
   Router(config-if)#ip add 172.16.0.1 255.255.255.252
   Router(config-if)#no shut
   Router(config-if)#exit
   Router(config)#int fa0/0
   Router(config-if)#ip add 192.168.0.3 255.255.255.0
   Router(config-if)#no shut
   Router(config-if)#exit

 Configure R3
   Router#conf t
   Router(config)#int loopback 0
   Router(config-if)#ip add 10.10.40.1 255.255.255.0
   Router(config-if)#no shut
   Router(config-if)#exit
   Router(config)#int Serial0/1/0
   Router(config-if)#ip add 172.16.0.2 255.255.255.252
   Router(config-if)#no shut
   Router(config-if)#exit

Step 6: Configure OSPF:

 Configure OSPF on R0
   Router(config)#router ospf 1
   Router(config-router)#router-id 10.2.2.2
   Router(config-router)#network 10.10.20.0 0.0.0.255 area 0
   Router(config-router)#network 192.168.0.0 0.0.0.255 area 0
   Router(config-router)#exit
   (wr works only on Router# - type "end" first to reach Router#)
   Router#wr

 Configure OSPF on R1
   Router(config)#router ospf 1
   Router(config-router)#router-id 10.1.1.1
   Router(config-router)#network 10.10.10.0 0.0.0.255 area 0
   Router(config-router)#network 192.168.0.0 0.0.0.255 area 0
   Router(config-router)#exit
   Router(config)#^Z
   Router#wr

 Configure OSPF on R2
   Router(config)#router ospf 1
   Router(config-router)#router-id 10.3.3.3
   Router(config-router)#network 10.10.30.0 0.0.0.255 area 0
   Router(config-router)#network 172.16.0.0 0.0.0.3 area 0
   Router(config-router)#network 192.168.0.0 0.0.0.255 area 0
   Router(config-router)#^Z
   Router#wr

 Configure OSPF on R3
   Router(config)#router ospf 1
   Router(config-router)#router-id 10.4.4.4
   Router(config-router)#network 10.10.40.0 0.0.0.255 area 0
   Router(config-router)#network 172.16.0.0 0.0.0.3 area 0
   Router(config-router)#exit
   Router(config)#^Z
   Router#wr

Step 7: Check connectivity (routes marked "O" = OSPF):

 On R0
   Router#sh ip route
   Router#ping 10.10.10.1

 On R1
   Router#sh ip route
   Router#ping 10.10.20.1

 On R2
   Router#sh ip route
   Router#ping 10.10.10.1

 On R3
   Router#sh ip route
   Router#ping 10.10.30.1

 Expected: !!!!!  Success rate is 100 percent (5/5)

Notes:
 - Document writes "ship route" in some places; the command is "sh ip route".
 - Serial link stays down? Run "clock rate 64000" on the clock-icon (DCE) end.
 - "wr" works only on Router#. R0: after "exit" in OSPF, type "end" (or Ctrl+Z) to reach Router# before "wr".
 - R3 section in the document starts at Router#conf t, so type "en" first.
