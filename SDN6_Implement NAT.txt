==================================================
PRACTICAL 6
AIM: Implement NAT
==================================================

Step 1: Add 2 Router-PT (Router0, Router1), 2 Switch-PT (Switch0, Switch1),
        2 PC-PT (PC0, PC1) and 1 Server-PT (Server0).

Step 2: Make automatic connection (connect in this order - first to last):
   * 1st: Router0 Fa0/0 --- Switch0
   * 2nd: Switch0 --- PC0 Fa0
   * 3rd: Switch0 --- Server0 Fa0
   * 4th: Router0 Serial2/0 --- Router1 Serial2/0   (network 192.162.10.0)
   * 5th: Router1 Fa0/0 --- Switch1
   * 6th: Switch1 --- PC1 Fa0
   (Flow: Router0 > Switch0 > PC0 > Server0, then Router0 > Router1, then Router1 > Switch1 > PC1)

Step 3: PC/Server > Desktop > IP Configuration > Static:
   * PC0: ipv4: 10.10.10.2, subnet mask 255.0.0.0, default gateway 10.10.10.1
   * Server0: ipv4: 10.10.10.3, subnet mask 255.0.0.0, default gateway 10.10.10.1
   * PC1: ipv4: 20.20.20.2, subnet mask 255.0.0.0, default gateway 20.20.20.1

Step 4: Router > Config tab > interface (Port Status On):
   * Router0 FastEthernet0/0: ipv4 10.10.10.1, subnet mask 255.0.0.0
   * Router0 Serial2/0: ipv4 192.162.10.1, subnet mask 255.255.255.0, clock rate 2000000
   * Router1 FastEthernet0/0: ipv4 20.20.20.1, subnet mask 255.0.0.0
   * Router1 Serial2/0: ipv4 192.162.10.2, subnet mask 255.255.255.0, clock rate 1200
   (Private/Public: Router0 side 10.10.10.0 / 50.50.50.0, Router1 side 20.20.20.0 / 60.60.60.0)

Step 5: Configure NAT on R0 (click Router0 > CLI; type "en" then "conf t" first):
   Router(config)#ip nat inside source static 10.10.10.2 50.50.50.2
   Router(config)#ip nat inside source static 10.10.10.3 50.50.50.3
   Router(config)#interface fa0/0
   Router(config-if)#ip nat inside
   Router(config-if)#exit
   Router(config)#interface serial2/0
   Router(config-if)#ip nat outside
   Router(config-if)#exit

Step 6: Configure NAT on R1 (click Router1 > CLI; type "en" then "conf t" first):
   Router(config)#ip nat inside source static 20.20.20.2 60.60.60.2
   Router(config)#interface fa0/0
   Router(config-if)#ip nat inside
   Router(config-if)#exit
   Router(config)#interface serial2/0
   Router(config-if)#ip nat outside
   Router(config-if)#exit

Step 7: Static routes:

 Router R0 with static information:
   Router(config)#ip route 60.0.0.0 255.0.0.0 192.162.10.2
   Router(config)#exit

 Router R1 with static information:
   Router(config)#ip route 50.0.0.0 255.0.0.0 192.162.10.1
   Router(config)#exit

Step 8: Check ip route:
 Router R0:
   Router#show ip route
 Router R1:
   Router#show ip route

Step 9: Test (Desktop > Command Prompt):
 On PC0:
   ping 60.60.60.2     (works - PC1's public address)
   ping 20.20.20.2     (fails - Destination host unreachable)
 On PC1:
   ping 50.50.50.2     (works - PC0's public address)
   ping 10.10.10.2     (fails - Destination host unreachable)

Notes:
 - Document's NAT commands start at the Router # prompt; type "en" and "conf t" first.
 - Stay in config mode from Step 5/6 to Step 7 (ip route is a config command), then "exit".
 - If the serial line stays red, set the clock rate on the clock-icon (DCE) end.
 - First ping may time out once (document's screenshot shows 3 of 4 replies).
 - Pings use the PUBLIC addresses (50.50.50.x / 60.60.60.x), not the private ones.
