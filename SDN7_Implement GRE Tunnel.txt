Step 1: Add 3 routers (1941): Router0 (R0), Router1 (R1), Router2 (R2).

Step 2: Connect through copper straight through wire (connect in this order):
   * 1st: Router0 gig0/0 --- Router1 gig0/0   (network 1.1.1.0/8)
   * 2nd: Router1 gig0/1 --- Router2 gig0/1   (network 2.2.2.0/8)
   (TUNNEL between Router0 and Router2 is made by commands - no cable.)

Step 3: IP addresses - REFERENCE LIST ONLY, no action needed here.
        Move to Step 4 (the IPs are assigned there using the commands):
   * R0: gig0/0 1.1.1.1/8  | lo 0 10.1.1.1/24
   * R1: gig0/0 1.1.1.2/8  | gig0/1 2.2.2.1/8 | lo 0 20.1.1.1/24 | hostname ISP
   * R2: gig0/1 2.2.2.2/8  | lo 0 30.1.1.1/24
   * Tunnel 1: R0 192.168.13.1/24 | R2 192.168.13.3/24

Step 4: Configure the routers:

 Configure Router R0
   Router>en
   Router#conf t
   Router(config)#int gig0/0
   Router(config-if)#ip address 1.1.1.1 255.0.0.0
   Router(config-if)#no shut
   Router(config-if)#int lo 0
   Router(config-if)#ip add 10.1.1.1 255.255.255.0
   Router(config-if)#no shut
   Router(config-if)#exit
   Router(config)#

 Configure Router R1
   Router>en
   Router#conf t
   Router(config)#int gig0/0
   Router(config-if)#ip add 1.1.1.2 255.0.0.0
   Router(config-if)#no shut
   Router(config-if)#int gig0/1
   Router(config-if)#ip add 2.2.2.1 255.0.0.0
   Router(config-if)#no shut
   Router(config-if)#int lo 0
   Router(config-if)#ip add 20.1.1.1 255.255.255.0
   Router(config-if)#no shut
   Router(config-if)#exit
   Router(config)#
   Router(config)#hostname ISP

 Configure Router R2
   Router>en
   Router#conf t
   Router(config)#int gig0/1
   Router(config-if)#ip add 2.2.2.2 255.0.0.0
   Router(config-if)#no shut
   Router(config-if)#int lo 0
   Router(config-if)#ip add 30.1.1.1 255.255.255.0
   Router(config-if)#no shut
   Router(config-if)#exit

Step 5: Configure GRE:

 Configure GRE on R0
   Router(config)#interface tunnel 1
   Router(config-if)#tunnel source gig0/0
   Router(config-if)#tunnel destination 2.2.2.2
   Router(config-if)#ip add 192.168.13.1 255.255.255.0
   Router(config-if)#no shut
   Router(config-if)#end

 Configure GRE on R2
   Router(config)#interface tunnel 1
   Router(config-if)#tunnel source gig0/1
   Router(config-if)#tunnel destination 1.1.1.1
   Router(config-if)#ip add 192.168.13.3 255.255.255.0
   Router(config-if)#no shut
   Router(config-if)#end

Step 6: Configure static routes:

 Configure Static route on R0:
   Router#conf t
   Router(config)#ip route 2.0.0.0 255.0.0.0 1.1.1.2
   Router(config)#

 Configure Static route on R2:
   Router(config)#ip route 1.0.0.0 255.0.0.0 2.2.2.1

Step 7: Check connectivity:

 Check connectivity from R0:
   Router#ping 192.168.13.3

 Check connectivity from R2:
   Router#ping 192.168.13.1

 Expected: !!!!!  Success rate is 100 percent (5/5)

Notes:
 - R2 static route: you are at Router# after "end", so type "conf t" first.
 - Before each ping type "end" to reach Router#.
 - R1 prompt changes to ISP after "hostname ISP".
 - Tunnel up message: Line protocol on Interface Tunnel1, changed state to up.
