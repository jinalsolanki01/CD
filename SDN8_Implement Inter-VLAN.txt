==================================================
PRACTICAL 8
AIM: Implement Inter-VLAN
==================================================

Step 1: Add 1 router (2911): Router0, 1 switch (2960-24TT): Switch0, 4 PC-PT: PC0, PC1, PC2, PC3.

Step 2: Connect the PC to switch via copper straight through wire (connect in this order):
   * 1st: PC0 Fa0 --- Switch0 Fa0/1
   * 2nd: PC1 Fa0 --- Switch0 Fa0/2
   * 3rd: PC2 Fa0 --- Switch0 Fa0/3
   * 4th: PC3 Fa0 --- Switch0 Fa0/4
   * 5th: Router0 gig0/0 --- Switch0 Fa0/24
   (Diagram labels PC0's switch port "fa0/0"; the commands use Fa0/1 for it.)

Step 3: ON SWITCH (click Switch0 > CLI):
   Switch>en
   Switch#conf t
   Switch(config)#vlan 10
   Switch(config-vlan)#name sales
   Switch(config-vlan)#exit
   Switch(config)#vlan 20
   Switch(config-vlan)#name market
   Switch(config-vlan)#exit
   Switch(config)#int fa0/1
   Switch(config-if)#switchport mode access
   Switch(config-if)#switchport access vlan 10
   Switch(config-if)#exit
   Switch(config)#int fa0/2
   Switch(config-if)#switchport mode access
   Switch(config-if)#switchport access vlan 20
   Switch(config-if)#exit
   Switch(config)#int fa0/3
   Switch(config-if)#switchport mode access
   Switch(config-if)#switchport access vlan 10
   Switch(config-if)#exit
   Switch(config)#int fa0/4
   Switch(config-if)#switchport mode access
   Switch(config-if)#switchport access vlan 20
   Switch(config-if)#exit
   Switch(config)#int fa0/24
   Switch(config-if)#switchport mode trunk
   Switch(config-if)#exit

Step 4: ON ROUTER: click Router0 > Config tab > GigabitEthernet0/0 > Port Status ON.

Step 5: Then in CLI (Router0 > CLI):
   enable
   configure terminal
   interface gigabitEthernet0/0
   no ip address
   no shutdown
   exit
   interface gigabitEthernet0/0.10
   encapsulation dot1Q 10
   ip address 192.168.10.1 255.255.255.0
   exit
   interface gigabitEthernet0/0.20
   encapsulation dot1Q 20
   ip address 192.168.20.1 255.255.255.0
   exit
   end
   write memory

Step 6: Configure the PC to their respective IP address (PC > Desktop > IP Configuration > Static):
   * PC0 (VLAN 10): ipv4: 192.168.10.2, subnet mask 255.255.255.0, default gateway 192.168.10.1
   * PC1 (VLAN 20): ipv4: 192.168.20.2, subnet mask 255.255.255.0, default gateway 192.168.20.1
   * PC2 (VLAN 10): ipv4: 192.168.10.3, subnet mask 255.255.255.0, default gateway 192.168.10.1
   * PC3 (VLAN 20): ipv4: 192.168.20.3, subnet mask 255.255.255.0, default gateway 192.168.20.1
   (Mask and gateways are NOT given in the document - these are the values used.)

Step 7: Test the connectivity from VLAN 10 to VLAN 20 from PC (in this order):
   On PC0, open Desktop > Command Prompt.
   * First, ping its own VLAN gateway:   ping 192.168.10.1
   * Then ping the other VLAN's gateway: ping 192.168.20.1
   * Finally, ping PC1:                  ping 192.168.20.2
   (Expected: replies. First ping may time out once - document shows 3 of 4 replies.)

Notes:
 - Wait about 30 seconds for the switch ports to turn green before testing.
 - Document writes "VLAN 1 to VLAN 2"; it means VLAN 10 to VLAN 20.
 - VLAN 10 = sales, VLAN 20 = market. Fa0/24 = trunk to the router.
